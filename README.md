# Anbumani-# 
🔐 Password Strength Checker

A beginner-friendly Python tool to check basic password strength in the Linux terminal.

## ✨ Features

- 🎨 Colourful terminal interface
- 🔒 Hidden password input
- 📊 Password strength classification
- 🔠 Uppercase and lowercase character checks
- 🔢 Number and special character checks

## 🛠️ Requirements

- Linux (Ubuntu or Kali Linux)
- Python 3

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd password-checker
   ```

3. Run the tool:

   ```bash
   python3 checker.py
   ```

## 📚 Purpose

This project was created for learning Python programming and basic cybersecurity concepts.

## ⚠️ Disclaimer

This is a basic educational password checker. It does not guarantee password security.
